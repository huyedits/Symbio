# Sponsors

Symbio is free, open source (Apache-2.0), and stays that way. Sponsorship
funds **continuity**: the 2,755-test suite kept green, measured model
benchmarks on real hardware published monthly, security fixes shipped within
days, and the correction→fine-tune→rollback learning loop maintained as the
model ecosystem churns underneath it.

You are not buying features. You are paying so a project with real measured
failures on record is still here, still maintained, next year.

## Where your money goes

| | |
|---|---|
| **Maintenance** | Keeping the suite green across MLA/MLX/model-family churn — the harness must keep working as models change under it |
| **Benchmarks** | Judge-free, measured, published: every claim in the README is reproducible by you from the bench/ directory |
| **Security** | The injection-scanning, sandbox and gates maintained against the current attack surface |
