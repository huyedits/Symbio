Local agent · Apple Silicon · Apache 2.0

Correct it once. It fine-tunes itself so it remembers.

Symbio is a personal agent that runs on your Mac. When you correct it, the correction becomes training data, a small LoRA update runs on your machine, and a regression battery rolls the update back if it made anything worse.

A correction becomes weights, not a longer prompt.

Putting fixes in a system prompt makes every turn slower and teaches the model nothing. Symbio changes the adapter instead, and only the adapter: the base model stays frozen.

  1. You correct it

    A plain "no, it's…" is detected. So is a failed tool call it later recovers from.

  2. It classifies the mistake

    Knowledge (a wrong fact) and reflex (the wrong shape of action) get different training recipes.

  3. Examples accumulate

    The threshold scales with the corpus, by log, clamped to 2–20. Severe mistakes pull it down.

  4. LoRA trains locally

    A short run on MLX. The model can also call its own train_adapter tool mid-conversation.

  5. The battery decides

    A golden set is re-scored. A run that made anything worse is rolled back.

Measured, then written down.

These are single runs from the project's README, on a 16 GB Mac. They show direction, and the README says so. It also records where the harness, not the model, was the thing in the way.

Why the caveats are on the page: the first version of one benchmark mimicked the real AWS CLI, and the model scored 13/13 before any training, because it was reciting from pretraining. Symbio's README keeps that story next to the results, along with a silent partial adapter load that once made a working model read 0/13.

A loop that trains itself needs brakes.

The training loss will not tell you a run made the agent worse. Each check below can refuse a run rather than print a warning.

Before

The corpus is checked

Broken tool-call samples are dropped, prompt masking is verified against the chat template, and LoRA keys are checked against the module tree.

After

Golden-set rollback

A regression battery is re-run on the new adapter. Consistent regressions roll back; flaky ones are retried first.

Always

Crash-safe training

An interrupted run is recorded and can be resumed, and the previous adapter is backed up before it is replaced.

Actions

Permission gates

Dangerous tools need explicit approval. Scheduled jobs that run unattended are denied by default.

Inputs

Untrusted content stays data

Web pages and tool output are wrapped as untrusted, and a security policy sits ahead of every editable prompt region.

Inspection

See what a fine-tune moved

weight_delta.py shows, module by module, how far each run moved the weights.

What it can do while it learns.

One installation on one machine. Notes, sessions, training data and adapters live in ~/.symbio.

Desktop

Drives the Mac itself

Reads windows through the accessibility API, so actions target numbered controls instead of guessed coordinates.

Browser

Live browser automation

Opens pages, fills forms by selector, and confirms a submission from the page itself rather than a toast.

Skills

Learnable skills

Write a procedure in Markdown and train a dedicated worker adapter for it. A headmaster model delegates to workers.

Memory

Notes and retrieval

Web research is saved as notes and retrieved as context. Junk notes and duplicate turns are pruned.

Anywhere

Telegram and a light window

Talk to your own instance from your phone, or open the desktop window: 28 MB resident when idle.

Always on

Scheduled jobs

symb watch keeps the model loaded and runs the cron table, so "every morning at 8" does not need a window open.

Install

Three commands on an Apple Silicon Mac.

The [mlx] extra is the inference and training engine. Upgrading the package never touches your workspace.

Machine
macOS on an M-series chip
Memory
16 GB+ recommended for the default 8B-class model; smaller presets exist
Disk
~8 GB for the default setup
Python
3.10 or newer
zsh
$ pip install "symbio-cli[mlx]"
$ symb setup
$ symb chat

Want to work on it? git clone https://github.com/huyedits/Symbio && ./install.sh. The test suite runs on Linux too; tests that need MLX skip there.
